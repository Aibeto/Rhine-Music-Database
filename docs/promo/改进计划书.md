# 改进计划书 · 从「明日方舟风格的概念片」改成「这个程序的宣传片」

对 m01283 三条否决的正面回应。结论：**三条全部成立，而且根因是同一个**——我按两张静态截图（`panel.png`、`detail_dark.png`）的「图像气质」设计了全片，从没读过场景代码，也没看过其余五张界面图。于是做出来的东西「像明日方舟」，但不像**这个程序**。

---

## 一、诊断：差在哪，用数字说

| | 程序里的事实 | 我的分镜里 |
|---|---|---|
| 镜头 | `NativeScene.cpp`：`m_eye = {-62.26, 35.98, 43.28}`、`m_aim = {-0.5, 1.1, 0.4}`、**`m_fov = 6.15`**（≈330 mm 长焦，从 76 m 外看） | 100 mm 为主，还有大量 24/18 mm 广角 |
| 场景 | 5 条车道 × 40 个档案槽，`cellPosition = {(lane-2)×5.2, −4.6, (row-15.5)×0.62}` | 凭感觉摆的书架，间距随手定 |
| 界面 | MiSans 四个字重（light/regular/demibold/bold），`Assets/fonts/misans-glyphs.json` 存的是**逐字轮廓路径**，units 1000，ascent 1044 | 用方块假字，或干脆没有字 |
| 交互 | 卡片抽出→归位（继承真实速度与角度）、脉冲、扫描解密、昼夜主题、装配体爆炸/合拢 | 一个都没有 |
| 开场 | `Assets/animation/boot-tracks.json`：**38 条真实关键帧轨道**（brandX 234→1、logo.draw 229–264、scan 487–568、orbit 543–568、highlightKeys 588–611） | 自己编的光柱 + 尘 |

**一句话根因**：这个程序的身份不是「明日方舟式的抽象几何」，而是 **编辑部排印 + 纸卡片 + 一堵 3D 档案墙**，三者叠在同一个画面里。我的分镜把第一层丢了，第二层做成了抽象图形，第三层完全没做。

**最关键的一条**：`m_fov = 6.15°`。这就是为什么程序截图看起来那么平、那么像等距投影——它是**从 76 米外用 330 mm 长焦看一堵 5.2 米宽的墙**。这个镜头参数本身就是风格的一半，而我用了完全相反的广角。

## 二、整改 A：界面即风格（回应第 1 条）

不是「加个 UI 装饰」，而是把程序的排印系统搬进 3D。

### A1. 字体：真实字形，不是方块
`misans-glyphs.json` 里有 MiSans 四字重的**轮廓路径**（每字 `advance` + `path`）。做一个小脚本把需要的字（约 60 个汉字 + 全套拉丁）转成 Blender 曲线并挤出 0.004 m —— 文字变成**有厚度的实体**，可以掠射、可以投影、可以被唱针划过。这一步同时解决「像 PPT 贴图」的问题。

### A2. 版式：三件签名件
- **巨大中文标题 + 小号 mono 拉丁副题**（`塞壬唱片-MSR` / `RHINE LAB / MUSIC DATABASE`）
- **发丝分隔线 + mono 字段头**（`# TITLE / 歌曲  ARTIST / 歌手  ALBUM / 专辑  TIME`）
- **巨型数字 + 斜杠**（`53 / 445`、`02 / 10`）

### A3. 材质：纸有厚度、有折角、有投影
现在是 0 厚度的发光面片。改成 **0.6 mm 纸板 + 0.15 mm 折角 + 一层极淡的接触阴影**（阴影只用一个 soft box 方向，仍不用真实灯光，靠 `hide_render` 假投影实现）。

### A4. 配色：不是纯黑白
程序是**暖灰纸**系：底色 `#E7E7E1`、奶油 `#EDEDEA`、墨 `#141613`、苔绿按钮 `#777B60`。我的片子把苔绿压成了近黑，画面偏冷。改为整片建立在这个暖灰上，**冷色只留给「机器在响应」的三帧**。

**受影响镜头**：02、03、11、17、22、23、24、28、31 —— 全部重做排印层。

## 三、整改 B：用行为说功能（回应第 2 条）

原则不变：**零旁白、零介绍文字**。卖点靠「做给你看」，一个动作说一件事。

### B1. 卖点 → 动作对照表

| 卖点 | 一个动作（不写字） | 落在哪镜 |
|---|---|---|
| 40 槽档案墙 / 5 车道分类 | 长焦横移扫过整墙，一条车道亮起、其余压暗 | 新 09 |
| 卡片抽出与归位 | 一张卡抬起到 0.4，转身，另一张从画外飞回原位并**减速停住** | 新 12 |
| 装配体爆炸/合拢 | 同一件东西散成 7 个零件（optical-core / lenses / carrier / frosted / fasteners / cover / label）再合拢 | 新 14 |
| 扫描解密 | 一道白环从中心扫过，扫过的区域从噪点变成清晰字形 | 新 16 |
| 昼夜主题 | 同一构图，纸白 ↔ 暗舱蓝黑，只换环境不换机位 | 新 18 |
| 播放队列 | 一列卡片沿 Z 轴排成队，最前一张被抽走 | 新 21 |
| 黑胶播放 | 唱针落盘、刻痕读成数据 | 06a、06c 保留 |

### B2. 替换清单
删掉 6 个纯抽象镜（12 塔、13 弧扇、14 椭圆盘、16 雾、18 X 交叉、08 圆环隧道），换成上表 6 个「功能镜」。**时长与拍格不动**，只换内容。

### B3. 为什么这样仍然「意识流」
因为功能镜全部**不给完整上下文**：只拍抽卡的那 0.4 米、只拍扫描环经过的一道缝。观众先感到「有个东西在动」，第二次看才发现「那是在切歌」。

## 四、整改 C：复刻程序场景（回应第 3 条）

### C1. 档案墙：按代码重建，不按感觉
```cpp
cellPosition(cell) = { (lane - 2) * 5.2, -4.6, (row - 15.5) * 0.62 }
```
5 条车道 × 40 槽；`fileLocation` 把索引映射到 `{lane, 12 + row}`。墙宽 5.2×4 = 20.8 m，高 0.62×40 ≈ 24.8 m —— **一面 20×25 米的档案墙**。这就是为什么长焦下它像一片无尽的格栅。

### C2. 相机：直接抄 `review()` 里的初值
`eye = (-62.26, 35.98, 43.28)`、`aim = (-0.5, 1.1, 0.4)`、`fov = 6.15°`（换算 36 mm 画幅 ≈ 331 mm）。分镜里所有「档案墙」镜头改用这组参数，气质立刻回到程序。

### C3. 开场：复刻真实的 boot 动画
`boot-tracks.json` 的 38 条轨道就是程序启动的全过程：
`brandX`（24 帧，字母从 234 收拢到 1）→ `logo.draw` / `logo.strokeWidth` / `logo.movingCut`（229–294，字标逐笔描出）→ `scan.*`（487–568，白环扫描）→ `orbit.*`（543–568，轨道成形）→ `highlightKeys`（588–611）。
按 60 fps 换算约 **10.2 秒**——正好是这支片子的第一幕。用它替换现在 01–03 的「光柱 + 尘」。

### C4. 模型：已有基础，补装配体
`archive-assembly.glb`（16 材质：Ivory_Edges 0.94 / Frosted_Polymer 0.985 / Titanium_Fasteners metal 0.82 / Amber_Optical_Inlay 0.48,0.18,0.052）和 `archive-cassette.glb` 已导入并换皮。缺的是**装配体**：`archive-assembly.json` 里的 7 个 part 还没拆开做过爆炸。

## 七、验收标准（可量化，不靠"感觉"）

1. **长焦一致性**：所有档案墙镜头的水平 FOV 落在 6.0–6.3°；投影近似等距。
2. **字形真实**：片中出现的中文/拉丁字符 100% 来自 `misans-glyphs.json` 的轮廓，无一方块假字。
3. **功能可见**：7 个卖点里至少 6 个能在片中找到对应的「一个动作」。
4. **场景一致**：随机抽 5 帧与程序截图叠图，档案墙的槽距/车道数/灭点位置误差 < 5%。
5. **纪律不变**：橙色 ≤ 3 帧、旁白 0 字、介绍文字 0 行、硬切率 100%（无叠化）。

## 八、风险与取舍

- **长焦会让画面变"闷"**：331 mm 几乎没有透视，动作幅度在画面上被压缩。对策：靠**运动**（横移、抽卡）而不是**机位**制造纵深；每幕至少保留一镜短焦做呼吸。
- **复刻 boot 动画有版权风险吗**：没有——这就是本项目的自有资产（`Assets/animation/boot-tracks.json`）。
- **真字形会显著增加物体数**：约 60 字 × 每字挤出后 1 个 mesh，可控；但要在 `assemble.py` 里并入 `hide_render` 隔离。
- **会牺牲一部分"意识流"**：功能镜比抽象镜"实"。折中办法是只给动作的局部（抽卡只拍 0.4 米），保留不完整性。
