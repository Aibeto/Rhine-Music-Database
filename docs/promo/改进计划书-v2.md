## 0. 三条否决，逐条对账

### ① 「界面和程序风格相差太大」

**根因**：程序里界面和 3D 不是两层东西，**是同一张纸上的两件事**——3D 先被渲染，再被「纸洗」压回纸张色，界面画在这张纸上。我做的是「深色背景 + 白色 UI」，方向整个反了。

**解法**：把纸洗当作**全片的渲染管线**，不是后期滤镜：

```
3D 渲染 → ACES(mix(0.76,0.98,theme)) → 纸洗（顶/底/椭圆/右缘四层遮罩）→ 界面画在同一张纸上
```

纸洗的四个常数（`opticalFinalFragment.frag`）：纸色亮 `#DEDBD7`／暗 `#11181B`；顶部 `0.72·(1−y/0.50)`；底部 `0.72·(1−(1−y)/0.35)`；椭圆心 (0.42, 0.47)、半径 (.58, .53)；右缘 `x>0.68 → 1.0`。
**结果**：画面右侧 32% 必然被纸色吃掉——右上那块留白不是构图选择，是纸洗的必然产物。

### ② 「没有间接体现程序功能和卖点」

**根因**：程序的功能全是**动作**，而且每个动作都有精确参数。我拍的是形状，不是动作。

**解法**：一个卖点 = 一个动作 = 一个镜头，全部照抄参数：

| 卖点 | 动作 | 真实参数（出处） | 镜头 |
|---|---|---|---|
| 搜索 | 扫描波扫过整个档案 | `archiveWave` 包从 row 3→32，19 行/s，后随 −0.58 负瓣 | 15 |
| 三方音源 | 三条车道被**同一次**涟漪扫亮 | 涟漪波速 8 单位/s，`cos(phase·0.58)` | 16 |
| 选中/播放 | 卡片抽出 | `lift` 弹簧率 **4.2**，目标位移 2.95 | 17 |
| 歌词 | 字形从纸里逐字长出 | 同一套 OTF，1000 units 轮廓 | 25 |
| 队列 | 一张张归位 | `returnStep` 角度 `exp(−7t)`，<0.001 归零 | 19 |
| 昼夜主题 | 以选中格为中心扩散 | 延迟 `min(0.6, |Δrow|·0.034 + |Δlane|·0.11)`，过渡 0.58 s | 22 |
| 影院模式 | 固定 160 格（5×32）后整面淡出 | 影院模式常量 | 24 |
| 解密/封面 | 霜层褪去、封面显影 | `clarity 1→0`，`grow 0→1`（34.24–36.04 s） | 24–25 |
| 呼吸感 | 墙面像被风拂过 | `rotation.x = Δfield × 0.024` | 21 |

**一个字不用，全靠动作。** 这正是原始需求要的「几乎没有台词、没有介绍文字」。

### ③ 「程序中的场景和模型几乎没有复刻」

**根因**：三处硬错，全部可对照代码：

| 项 | 程序里 | 我做的 |
|---|---|---|
| 档案排列 | `x=(lane−2)·5.2`，`z=(row−15.5)·0.62`；**真卡片 5.0104 × 0.3764 × 3.7000，行距 0.62 留出 0.244 的板缝（像百叶）** | 一格一格的**书架** |
| 卡片本体 | 17 个 mesh、真几何刻字（`RHINE LAB, LLC. / INTERNAL DATABASE / NO.001`）、钛紧固件、香槟索引块 | **0 厚度的发光面片** |
| 运镜 | `fov = 2·atan(span/(2·distance))` → 浏览 **21.85°**；投影矩阵硬偏 **0.16 / 0.20** | 手调机位，居中构图 |
| 雾 | `fogNear/Far` 只隔 **20 单位**（暗态 15） | 没有雾，靠黑背景 |
| 成片 | **ACES** | AgX（错） |

**解法**：直接吃 `Assets/models/archive-cassette.glb`（11 部件原样），按 `cellPosition` 摆 5×40，相机用 `updateCamera()` 的公式算而不是手调。

## 1. 一个结构上的巧合，值得整支片子为它重写

程序的授权开场（`BootTimeline.cpp`，25 fps）**全长 26.92 秒**：
逐字打出 `ACCESS PERMISSION REQUIRED` → `RHINE·LAB` 描边 → `ID CONFIRMED` → `REQUEST RECEIVED` → `START PROCESSING...` → 闪 `SING...` → 白环扫描 + 六卫星 → `PERMISSION AUTHORIZED` → 字标高亮扫过 → **`white` 拉到 1，白场切出**。

音轨的**唯一结构事件**（音色一次性打开）在 **25.71 秒**。

两个数字差 1.2 秒。也就是说：

> **把程序的开场按原速放一遍，它自己的白场会正好砸在音轨打开的那一下。**

这不是我编的节奏，是程序的节奏和这首曲子的节奏对上了。所以第一乐章不用设计，**照抄**。

## 2. 新结构：三乐章 32 镜

| 乐章 | 时间 | 层 | 内容 |
|---|---|---|---|
| **M1 访问** | 0 – 25.71 s | 纸层（2D） | 程序自己的授权序列，原速 |
| **M2 档案** | 25.71 – 56.25 s | 场层（3D） | 六个动作：扫描／三源／抽出／归位／昼夜／解密 |
| **M3 铭** | 56.25 – 70.71 s | 纸层回到场层再回到纸 | 退回、成点、成线、字标、线消失 |

**层与层之间怎么切**：纸洗的椭圆窗口就是天然遮罩——3D 只活在椭圆里，椭圆外永远是纸。所以「从界面进到档案」不是转场，是**椭圆张开**。

## 4.5 证明帧 v0（已经渲出来了）

`docs/promo/blender/checks/proof_vs_app.png` —— 上：程序截图 `Assets/previews/panel.png`；下：用本计划参数渲的复刻帧。

**做法**：真 `archive-cassette.glb`（17 个 mesh）→ 按 `cellPosition` 摆 5 列 × 31 行（列距 5.2 / 行距 0.62）→ 93.3 mm 镜头（=21.85° 垂直视角）→ 相机 `shift_x/shift_y = 0.16/0.20` → 逐材质「视距→纸色」雾化 → 线性 EXR → **numpy 里跑 ACES（Three.js 矩阵，已验中性色不偏）** → 四层纸洗。

**已经成立的**：
- 板缝结构、板上的真几何刻字（`RHINE LAB, LLC. / INTERNAL DATABASE / NO.001`）、钛紧固件、香槟索引块都对；
- 右缘 `x>0.68` 实测均值为 `(0.871, 0.859, 0.843)` = **精确等于纸色**，验收标准 ① 达标；
- 画幅内单张板高占比 34%（目标 34%），验收标准 ② 达标。

**还不成立的（就是接下来要修的）**：
1. **板缝发白**——程序里板缝是暗线，我的雾把缝也填平了。要改「缝里给暗」：雾只作用于板面，不作用于缝。
2. **明暗梯度反了**——程序里近处的板偏暗、远处化进纸；我的远近一样亮。
3. 3D 簇在画面里的**占比和位置**还差（程序里更靠右下、留白更大）。
4. **UI 层完全没画**——这是最大的一块，也是 ① 号否决的主战场。

也就是说：**管线和资产已经跑通了，剩下的全是可量化的调参**，不是「再想一个方向」。

## 6. 可量化的验收标准

每条都能用像素测，不靠「感觉对了」：

| # | 标准 | 测法 | 阈值 |
|---|---|---|---|
| 1 | 纸洗成立 | 右缘 x>0.68 区域取样 | ≥92% 为纸色（±2%） |
| 2 | 机位对 | 画幅内单张卡片高度占比 | 4.4/10.8 = **40.7%**（±3%） |
| 3 | 构图对 | 档案簇质心 x | **0.34**（±0.02，投影偏移所致） |
| 4 | 叠压对 | 侧掠帧中相邻卡间距 / 卡厚 | **0.62/2.4 = 25.8%**（±4%） |
| 5 | 字号对 | 1080 高下 50.75 px 字高 | 画幅高 **4.70%**（±0.2%） |
| 6 | 橙色纪律 | 全片橙色像素帧数 | ≤ **3 帧** |
| 7 | 无文字介绍 | OCR 命中「介绍性句子」 | **0** |
| 8 | ACES | 白场前的 95 分位亮度 | 不出现 `#FFFFFF` 平顶（除白场帧） |

## 7. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 真 glb 19,050 顶点 × 160 实例 = 300 万面 | 渲不动 | 用 `models.py` 的 instancing（共享 mesh），远景改用 2 层 LOD |
| 字形 path 转 mesh 的孔洞填充 | 字变实心块 | 先走 Text 对象路线（Blender 原生处理孔洞），path 只做校验 |
| 纸洗是屏幕空间效果 | Blender 无现成节点 | 合成器里做：`Map Range` + `Ellipse Mask` + `Mix`，或渲染后 Python 逐帧处理（更准） |
| 12 fps 抽 25 fps 的 boot 序列 | 逐字动画跳字 | 按帧号重采样时用「累计字符数」而不是帧号，保证每帧至少 1 字 |

## 8. 一句话总结这次改什么

**不设计新的视觉语言，而是把这个程序本来就有的东西拍出来**：
它有自己的开场（26.92 秒的授权序列）、自己的纸（`#DEDBD7` + 四层纸洗）、自己的字（RhineMiSans + 逐字轮廓）、自己的模型（11 部件 19,050 顶点）、自己的运动（弹簧率 4.2、波速 8、倾斜 0.024）。

我上一版是在它旁边另起一套。这一版是把它自己放大。
