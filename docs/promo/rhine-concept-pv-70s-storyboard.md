## 0 · 一句话

**一粒尘埃的记忆容量，等于一整个谱系。**

70 秒里，摄影机在同一种形状的五次变形之间穿行一次：**尘 → 盘 → 匣 → 线 → 点**。
它不是功能介绍片，是一份档案在自我陈述。

## 0.5 · 考据：改掉设计的三条（保留备查）

### ① 莱茵生命的官方视觉是「白 + 高亮橙」，不是绿

GameLook 引述《孤星》项目组：主色调是**略带聚酯材质的白色 + 机械交互的高亮橙色**；底层美术语言是"简单却有张力的平面、曲面结合"；明确受**迪特·拉姆斯**影响——"少即是好"，用克制的笔触传递庞大数据量。

> **落地**：全片黑白灰 + 苔绿暗部，**橙色是"机械交互"的专属色，全片 3 次、每次 ≤3 帧**（9.0s 针落 / 52.5s 播放键 / 65s 片尾方块）。任何一帧橙色面积 ≤2%。这条纪律本身才是拉姆斯。
> 来源：[GameLook](http://www.gamelook.com.cn/2023/05/516801)

### ② 方舟的高级感来自「素材的变形与转换」，不是画面华丽

「崔林特尔梅之金」十几秒：金粉 → 撒在音箱上的沙粒 → **克拉尼声音图形** → 金律法卫标志 → 平行频谱波 → 双子女皇塔。

> **落地**：6 处不做剪切的形变转场（§5）+ 第 7 镜克拉尼图形。**声音让沙粒成形**——这比任何频谱可视化都更像方舟。
> 来源：[BB姬 PV 分析](https://www.163.com/dy/article/KU22VDBD0526FP3N.html)

### ③「孤星」的暗线是"上升"，而且做得极其朴素

海拔图每出现一次高一截，BGM 到顶时线条组成火箭。

> **落地**：一条**贯穿全片的 1px 刻度尺**，出现 7 次、每次高一格、从不解说。**片尾那条 1px 横线就是第 7 格。**

**另外两条（已用）**：学「辞岁行」用**缺席**（全片无手、无耳）；学「十字路口」让**配乐叙事**（三音动机四次变奏）。

> 可信度：技法描述来自二手拆解，非官方声明，但片子里肉眼可验；①的"白+橙"与"拉姆斯"出自 GameLook 引述项目组。

## 2 · 视觉语法

### 2.1 调色板

| 色 | 值 | 用途 | 出现 |
|---|---|---|---|
| 纸白 | `#E7E7E1` | 档案库、光、白闪、片尾 | 全片 |
| 墨 | `#141613` | 字、线、剪影 | 全片 |
| 苔绿 | `#777B60` | **只做暗部反射**，不做光源 | 全片 |
| 冷白 | `#F2F7F4` | 唯一的发光体 | 全片 |
| **莱茵橙** | `#E8622A` | **只属于机械交互** | **3 次 · 每次 ≤3 帧** |

### 2.2 材质分工

- **喷砂铝** — 唱盘、针、机械件（§2.6 M1）
- **聚酯白** — 档案盒外壳，官方语汇（M2）
- **纸浆** — 盒内、标签（M3）
- **半透树脂** — 晶体（M4）
- **氧化玻璃** — 全息 UI（M5）
- **尘埃** — 全片的时间（M6）

### 2.3 镜头与运动

- 焦段：**25mm** 穿行 / **50mm** 中景 / **100mm 微距**。
- 光圈：T2.0–2.8；只有第 13、24 镜用 T5.6 保层次。
- 24fps 基准；闪切段抽帧到 **12fps 步进**（实测 12 最稳，低于 10 变成卡顿）。
- 运动只有两种：匀速漂移 / 指数缓入缓出。**不许弹跳、不许手持抖动。**

### 2.4 三条铁律

1. **每镜只有一个光源**，第二光源只能来自反射。
2. **文字永不可读**（见 §2.5）。
3. **禁止叠化。** 转场只有：硬切、白闪、黑场、物体擦过镜头、形变。

### 2.5 零文本策略

全片允许出现的"字"只有四种：

1. **伪字形** — 2px 高的色块，远看是字，近看是噪声。
2. **刻度与条码** — 纯图形，无语言信息。
3. **片尾字标** — 唯一真字，只署名，不承担说明功能。
4. **缺席** — 该有字的地方空着。

## 2.6 · 材质圣经

> A 方向成败全在这里。以下参数按 Blender / Principled BSDF 口径给，C4D / Redshift 可平移。

### M1 · 喷砂铝（唱盘 / 针 / 机械件）

| 项 | 值 | 备注 |
|---|---|---|
| base color | `#B8BCB6`，linear 0.52–0.58，微冷 | 不要纯灰，会显塑料 |
| roughness | **0.42–0.50** | 亚光。>0.55 变水泥，<0.35 变不锈钢 |
| anisotropic | 0.30，方向沿**车削同心圆** | 这一项是"高级"和"廉价"的分界线 |
| normal | 车纹 0.08 + 细颗粒噪声 0.03 | 车纹必须真实同心，不能是拉丝贴图平铺 |
| 边缘磨损 | 曲率遮罩，宽度 0.5–1.5mm | 只出现在棱角，**不许均匀** |
| 指纹 | 3 处，roughness 降到 0.25 的油脂层 | 不要贴"指纹图"，要改粗糙度 |

**禁忌**：镜面反射、clearcoat、任何形式的镀铬感。

### M2 · 聚酯白（档案盒）

| 项 | 值 | 备注 |
|---|---|---|
| base color | `#E7E7E1` | linear ≈ 0.79 |
| roughness | 0.55 | 均匀，不要噪声 |
| coat | weight 0.15 / roughness 0.35 | 制造"薄涂层"，不是漆 |
| 透光 | transmission 0.02 | 只让边缘 0.3mm 有极轻微透光 |
| 积灰 | 底部 15% 高度，AO 驱动 | 上部永远干净 |

**禁忌**：白值过曝。暗环境里锁 **0.72–0.80**，给高光留余量——否则盒子会变成一块发光的白板。

### M3 · 纸浆（盒内 / 标签）

roughness 0.85；`#D9D8CE`；纤维各向异性 normal 0.06。
**关键**：边缘起毛必须靠 **0.2mm 碎边 displacement**，贴图做不出来——这是"真纸"和"纸贴图"的全部区别。

### M4 · 半透树脂（晶体）

IOR 1.49 / transmission 0.85 / roughness 0.12；体积散射 density 0.02，色微暖；色散 **0.02**（宁少勿多）；内部气泡 3–5 个，有悬浮杂质。
**禁忌**：色散开到 0.1 以上就变成水晶球，不是方舟。

### M5 · 氧化玻璃（全息 UI）

厚 2mm，边缘染苔绿；表面 3–5 个气泡、2 处污渍；轻微色散。
**核心**：**每条线亮度只有 0.3，靠环境反射才看得见。** 这条决定它是"高科技"还是"网页"。自发光一拉满，整片立刻变 PPT。

### M6 · 尘埃（全片的时间）

粒径 0.3–2mm 分布（**不均匀**）；只有 **3% 在焦平面**；布朗运动 + 0.02m/s 上升气流。
**第 27 镜的尘埃必须与开场是同一批粒子、同一位置，只是静止。** 这是全片唯一的"时间"证据，做错就白拍。

---

### 2.7 · 光照纪律

- **色温**：5600K（日光感）或 4300K（略暖的机构感）。全片只选一个，不许混。
- **反差比 8:1**，暗部不许死黑，保留 0.02 的 lift。
- **体积光只用在 3 个镜头**：1、27、28。其余全靠反射——体积光一滥用就变游戏 CG。
- **Bloom**：阈值 0.9、半径 0.02。只允许出现在过曝帧（26 镜）。
- 全片**不出现暖色光**。橙色是材质色，不是光。

## 3 · 时间结构：跟着音轨走，70.71 秒 = 112 BPM × 33 小节

> 这一节是照着那条 FLAC 重做的，不是照 BPM 猜的。原来那版写 96 BPM × 28 小节，拍子对不上任何东西 —— 现在对上了。

### 3.1 音轨实测

`塞壬唱片-MSR,Erik Castro - Rhine Lab.LLC.flac` · 48 kHz / 24 bit / FLAC

| 测什么 | 数 | 意味着什么 |
|---|---|---|
| 时长 | 77.679s | 比 70s 长 7.7s，必须取舍 |
| 速度 | **112.0 BPM** | 144 个包络峰，峰间距中位 0.5360s、标准差 0.0148 |
| 一拍 / 一小节 | 0.5357s / 2.1429s | 全片每一个切点都挂在这个格上 |
| 相位 | **0.000** | 文件头就是第一拍，不用找起点 |
| 重音 | **没有** | 按 2/4/8/16/32 个脉冲折叠，组内起伏 <1 dB |
| 音高 | **没有** | 长时平均谱无谐波峰；20–60Hz 有 55dB，8–16kHz 只剩 4.6dB |
| 动态 | **没有** | RMS −11.4 dBFS，0→74.5s 浮动 ±0.6 dB |
| 结构 | **只有一次** | 亮度质心 875→2576Hz，发生在 25.7–30s，之后不再关 |
| 结尾 | 74.5s 起 | 指数淡出 2.5s 到 −39 dB，是它自带的结尾 |

> 一句话：**这条曲子是一台泵。** 它给你一条永不换挡的脉冲，不给你副歌、不给你和声、不给你一个能对上的音。所以画面的全部情绪，必须自己造。

### 3.2 剪掉开头两小节

删掉开头 **2 小节 = 4.2857s**（静止织体，删了听不出来），剩 **33 小节 = 70.714s**。切口正落在第 8 拍上 —— 切在脉冲的正中，接缝听不出来。

- 画面 0 秒 = 原曲 4.2857 秒
- 成片 70.714s，音频总长 73.4s（留 2.7s 尾巴，别剪掉，那是结尾）

### 3.3 幕表（拍是主单位）

| 幕 | 名称 | 时码 | 拍 | 时长 | 功能 | 能量 |
|---|---|---|---|---|---|---|
| 0 | **尘** | 0:00.0–0:04.3 | 0–8 | 4.29s | 无。只有空气 | ▁ |
| 1 | **生** | 0:04.3–0:12.9 | 8–24 | 8.57s | 物质诞生 | ▃ |
| 2 | **藏** | 0:12.9–0:25.7 | 24–48 | 12.86s | 档案库显形 | ▅ |
| 3 | **溯** | 0:25.7–0:39.6 | 48–74 | 13.93s | 坠落 / 闪切 | ▇ |
| 4 | **鸣** | 0:39.6–0:56.3 | 74–105 | 16.61s | 界面成形，峰值 | █ |
| 5 | **寂** | 0:56.3–1:04.3 | 105–120 | 8.04s | 抽空 | ▂ |
| 6 | **铭** | 1:04.3–1:10.7 | 120–132 | 6.43s | 落款 | ▁ |

**能量曲线仍然是断崖**：一路推到 53.0s 的峰值，然后硬切进静默。不缓降。

### 3.4 三条时间纪律

1. **除第 19 镜的 10 刀，每个剪辑点都落在 0.536s 的拍格上。** 32 个切点，一个不差。观众说不出为什么，但会觉得"稳"。
2. **25.7s 是这条音轨唯一的音乐事件**（音色一次性打开）。那个位置必须放全片第一次"放大"—— 第 13 镜，档案库显形为唱盘。
3. **结尾不要跟淡出对抗。** 音乐自己淡 2.5 秒，画面在 70.714s 直接黑掉。让观众听见那 2.5 秒的残响，那是白送的。

## 5 · 形变链（本片唯一真正难的部分）

**六处转场不做剪切。** 形状 A 在原地长成形状 B，一个镜头完成。

| | 位置 | 形变 | 实现 | 时长 |
|---|---|---|---|---|
| **M1** | 10.7s | 克拉尼内圈 → 隧道入口 | 圆的边缘向纵深拉伸成管壁；内圈半径不变，外圈被"拉长" | 3.0s |

| **M4** | 42.3s | 光带 → UI 网格 | 光带展开时不是散开，而是"被拉直"；直线交点先出现，再长出细线 | 2.5s |

## 8 · 声音设计

**无旁白、无对白、无字幕。而音乐也不叙事 —— 它只负责托住。**

### 8.1 这条曲子能给什么、不能给什么

| 给 | 不给 |
|---|---|
| 一条 0.536s 的恒定脉冲（132 拍） | 动机。没有可复现的旋律 |
| 一次音色开口（25.7–30s） | 和声。零音高材料 |
| 一个天然的 2.5s 结尾淡出 | 重拍。它没有小节感 |
| 恒定的 −11.4 dBFS 电平墙 | 副歌、drop、任何可以"踩"的结构 |

> 所以上一版设计的"三音动机四次变奏"**作废** —— 让画面去凑一个不存在的动机是错的。声音只做底板，叙事全部交给音效。

### 8.2 音效表（音乐不换，音效换）

| 幕 | 音效 | 做法 |
|---|---|---|
| 0 尘 | 磁带底噪、空气、40Hz 心跳 | 极轻，比曲子低 24dB 以上，只在脉冲之间可闻 |
| 1 生 | 电流、晶体「叮」、卡扣「咔」、沙粒 | 沙粒那镜（第 7 镜）是全片唯一一次"声音有形状" |
| 2 藏 | 纸摩擦、机械咔哒、薄片刀锋 | 咔哒要**贴着** 0.536s 的格走，别自己造节奏 |
| 3 溯 | 噪声墙、心跳、10 记打击 | 见 8.3，这 10 记是全片唯一的"反拍" |
| 4 鸣 | UI「嗒」×12、扫频、冲击波 | 12 声「嗒」均匀分布在 16.6s 里，最后一声落在峰值前 1 拍 |
| 5 寂 | 耳鸣高频、混响尾巴 | 曲子还在响，但音效全部撤掉 —— 让"没有"本身成为声音 |
| 6 铭 | 一声极轻的「叮」 | 然后什么都不加，让淡出自己走完 |

### 8.3 第 19 镜：10 刀跑赢 132 拍

曲子每 **0.536s** 一记脉冲，第 19 镜每 **0.429s** 一刀。**刀比脉冲快 20%。**

所以这 4.3 秒里，画面会一路追赶、超过、然后把音乐甩在身后 —— 观众感到的"失速"不是错觉，是算出来的。这是全片唯一一处画面不等音乐。

**10 记打击要叠在曲子自己的脉冲上**，不要另起节奏：该重合的时候重合，该错开的地方让它错开，错开本身就是内容。

### 8.4 三条混音纪律

1. **别再往上叠 braam / riser / 鼓组。** 这条曲子已经是 −11.4 dBFS 的满电平墙，峰值还过了 0 dBFS。再叠就不是"加厚"，是"糊"。
2. **先做减法再做加法。** 给音效腾空间的办法只有两个：等脉冲之间的空隙（每拍有约 200ms），或者等那 2.5 秒尾巴。
3. **最后不要补任何声音。** 淡出是它自己的。你补的那一下，会把它变成"配乐"，而不是"一台还在运转的机器关掉了"。

## 9 · 制作路线与工时

### 9.1 三条路线，选中间那条

| | 路线 | 做法 | 工期 | 代价 |
|---|---|---|---|---|
| A1 | 全 3D | Blender / C4D 全场景 | 3–4 周 | 最可控，但材质最容易假，且贵 |
| **A2** | **实拍微距 + 3D 合成**（推荐） | 5 条实拍微距撑质感，3D 只做档案库 / UI / 克拉尼 | **1.5–2 周** | 需要半天棚拍 |
| A3 | 全 AI 生成 | 提示词 + 后期统一 | 3–5 天 | **做不出 §5 的形变链**，只能硬切，降一档 |

**为什么推荐 A2**：A 方向赌的是材质，而**真材质是 AI 和 3D 都最难伪造的**——尤其指纹、纸纤维、沙粒。五条微距实拍（水杯、针尖、手、CRT、水滴）成本不到一天，却能把整片质感拉起来。
